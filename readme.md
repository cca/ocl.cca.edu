# Open Collaboration Lab

This is a mirror of the Open Collaboration Lab site which was hosted at [ocl.cca.edu](http://ocl.cca.edu). It is part of the [CCA Web Archive](https://cca.github.io/cca-web-archives/).

The mirrored site was created with `wget`:

```bash
wget --mirror --convert-links --adjust-extension --page-requisites --no-parent --domains=ocl.cca.edu http://ocl.cca.edu
```
